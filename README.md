# Cost Control / Control de Gastos

EN

This is my first project. I started as a self-taught programmer learning Python, and I am still learning every day.

I wanted to take things a step further by building a real project to learn how to manage and maintain software projects using GitHub.

I have used AI as a learning tool through the Socratic method, focusing on understanding concepts rather than receiving direct answers. Thanks to this approach, I learned about CRUD operations, the importance of user experience, and several libraries and development practices that I was not familiar with before.

This project is a CLI-based application for tracking expenses. It runs through main.py and includes the basic Create, Read, Update, and Delete (CRUD) functionalities.

The project is still a work in progress and there is plenty of room for improvement. I would greatly appreciate any constructive feedback, suggestions, or recommendations.

My English is not very strong yet, but I am working on improving it every day and hope to reach a solid level over time.
